# dh-codingchallenge-keyloop

## Intelligent Inventory Dashboard

A lightweight real-time inventory dashboard is available at:

- `/home/runner/work/dh-codingchallenge-keyloop/dh-codingchallenge-keyloop/index.html`

### Features

- Real-time dealership stock KPIs (total units, in-stock units, low-stock models, average days in stock)
- Inventory table with model-level details
- Intelligent replenishment risk classification and recommendations
- Smart alerts for high-demand, low-stock vehicles
- Filters by make, risk level, and model search
- Simulated live inventory updates every 5 seconds
